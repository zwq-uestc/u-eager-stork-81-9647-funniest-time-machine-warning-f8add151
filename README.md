Entrants write a single warning label for a time machine, 120 characters at most, aiming for the biggest laugh. An AI judge reads the labels two at a time against the judge brief published with the bounty and keeps the funnier one, in private rounds while entries are open and once more at the close. The funniest label takes the $2 first place reward. Entry is free and entries stay open for 40 hours.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
